# Core Rules (Always Follow)

## Next.js Awareness
- Do NOT assume default Next.js behavior
- Always verify from: node_modules/next/dist/docs/
- Follow latest conventions and avoid deprecated patterns

## SEO (MANDATORY)
- Use semantic HTML (header, nav, section, article, footer)
- Each page MUST have:
  - Unique title
  - Meta description
- Maintain proper heading hierarchy (h1 → h6)
- Ensure fast loading and accessibility

## Reusability
- Build reusable components only
- Avoid duplication
- Keep components modular and scalable

## Design Rules
- Avoid generic or template-style designs
- Follow clean, professional IT company UI
- Focus on typography, spacing, and clarity
- Keep design simple and content-focused

## Responsiveness
- Mobile-first approach
- Must work on all screen sizes
- Use Bootstrap grid + custom CSS

## Tech Rules
- Use Bootstrap + normal CSS only
- Avoid heavy libraries
- Keep code lightweight and optimized

## Code Quality
- Write clean, readable code
- Use meaningful naming
- Keep components small and focused
- Avoid unnecessary complexity

## Performance
- Optimize images and assets
- Avoid unnecessary re-renders
- Use lazy loading where possible

## Restrictions
- Do NOT use templates or generic AI layouts
- Do NOT duplicate code
- Do NOT ignore SEO structure

## Goal
Build a scalable, SEO-optimized, professional IT company website with reusable architecture.
